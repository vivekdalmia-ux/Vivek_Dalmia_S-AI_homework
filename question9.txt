Question Title -> Build Pipeline Directory Tree

Question Link -> https://my.newtonschool.co/playground/code/r2ui5gw5lhqt?lecture_hash=n9ynhcuvkld8

Solution :
    mkdir -p pipeline/stages/build
    mkdir -p pipeline/stages/test/unit/integration
    mkdir -p pipeline/env/staging
    mkdir -p pipeline/env/prod
    mkdir -p pipeline/artifacts/old

    chmod 750 pipeline/stages
    chmod 770 pipeline/artifacts
    chmod 700 pipeline/env

    cd pipeline/stages/build/
    touch app.py config.json NOTES.md
    echo "Build stage initialized." > NOTES.md

    cd ../..
    cd artifacts/old/
    touch build.log test.log deploy.log
    chmod 640 build.log test.log deploy.log

Approach :
    1. First created 2 folders inside stages folder of pipeline folder 
    2. Then created 2 folders inside env folder of pipeline folder
    3. Then created 1 folders inside artifacts folder of pipeline folder
    4. Then Changed the permissions of stages folder inside pipeline folder to "750" -> all for owners, read and executive for groups ,none for others
    5. Then Changed the permissions of artifacts folder inside pipeline folder to "770" -> all for owners and groups, none for others
    6. Then Changed the permissions of env folder inside pipeline folder to "700" -> all for owners , none for groups and others
    7. Then created "app.py ,config.json, NOTES.md" files inside build Directory created above and added content "Build stage initialized." inside "NOTES.md" File
    8. Then moved to "old" created in artifacts Directory.
    9. Then created "build.log test.log deploy.log" files there and gave "640" -> Read and write to owner, read to groups and none to other permissions to all files
